# Security and data-safety reports

For a suspected security vulnerability, use
**[Report a vulnerability](https://github.com/morishuz/piko/security/advisories/new)**
to contact the maintainers privately through GitHub. Please keep sensitive or
exploitable details out of public issues while the report is investigated.

Include the Piko version, macOS version, device model, and steps to reproduce
using disposable files where possible. Do not include private files, serial
numbers, or unreviewed diagnostic exports. Piko never uploads diagnostics
automatically.

Ordinary bugs can be reported in
[Issues](https://github.com/morishuz/piko/issues), without private data. If an
operation may have lost or changed data, stop writing to the affected device
until the result has been investigated.

Piko is preview software. Fixes target the latest version; there is no separate
long-term support branch.
