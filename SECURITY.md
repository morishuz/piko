# Security and data-safety reports

Do not post private files, filenames, serial numbers, or unreviewed diagnostic
reports in public issues. Piko never uploads diagnostics automatically.

For a vulnerability, use **Security → Report a vulnerability** on this repository
when available. If private reporting is unavailable, open an issue asking for a
private reporting channel without including sensitive or exploitable details.

Include the Piko version, macOS version, device model, and a minimal reproduction
using disposable files where possible. If an operation may have lost or changed
data, stop writing to the affected device until the result has been investigated.

Piko is preview software. Fixes target the latest version; there is no separate
long-term support branch. See the MIT license for warranty terms.
