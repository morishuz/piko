# Changelog

## 0.15.5 — 2026-10-18

Build 68.

### Added

- Click the drive icon beside the folder path to return to the storage root.

### Changed

- The sidebar shows overall transfer progress weighted by file size, a processed
  file count, and cancellation controls. The main pane shows a compact current-file
  status instead of a second progress bar.
- Connection problems appear beside the Connect button with a Try Again action.
- Read-only storage uses a small lock icon to the left of the drive and path,
  with clearer unavailable-action tooltips and no unnecessary Bin warning.
- The browser background matches the file list in light and dark mode.
- Missing thumbnail previews retain their file icons without an extra pop-up.

For earlier releases, see the [published release history](https://github.com/morishuz/piko/releases).
